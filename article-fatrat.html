Comment pirater un téléphone Android avec FatRat ?

22 Août 2026 Lecture : 6 min Android, FatRat, Pentesting, RAT
📱 FatRat
⚠️ Avertissement légal : Cet article est à but éducatif uniquement. L'utilisation de FatRat pour accéder à un appareil sans autorisation est ILLÉGALE et peut entraîner des poursuites judiciaires. La cybersécurité est un métier qui doit être exercé dans le respect des lois.

FatRat est un outil open-source utilisé en pentesting pour générer des payloads (charges utiles) qui permettent de prendre le contrôle d'un appareil Android à distance. Il est utilisé par les experts en cybersécurité pour tester la sécurité des smartphones.

🧰 Qu'est-ce que FatRat ?

  • Développeur : Screetsec
  • Langage : Python
  • Fonction : Génération de payloads Android (APK) pour l'obtention de shell inversé
  • Plateforme : Linux (Kali Linux recommandé)

🎯 Comment ça fonctionne ?

  1. Configuration : L'attaquant configure FatRat avec son adresse IP et son port.
  2. Génération : FatRat crée un fichier APK malveillant.
  3. Propagation : L'APK est envoyé à la victime (phishing, téléchargement).
  4. Exécution : La victime installe l'APK.
  5. Contrôle : L'attaquant obtient un shell inversé et peut :
  • Accéder aux messages 📨
  • Activer le microphone 🎙️
  • Localiser le téléphone 📍
  • Capturer des photos 📸
  • Récupérer des fichiers 📁

🔧 Exemple de commande FatRat

git clone https://github.com/screetsec/FatRat cd FatRat chmod +x setup.sh ./setup.sh ./fatrat

Choix du payload :

[5] Android Payload (msfvenom) [2] Android APK (RAT + Reverse Shell)
